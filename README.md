# MANIKANDAN LATHE – Welding Works App (ml-klm)

A modern, high-performance web application built for **MANIKANDAN LATHE – Welding Works** (Kallimandhayam, Dindigul District, Tamil Nadu).

## 🚀 Key Features
- **Public Showcase & Landing**: Dual-language support (English & தமிழ்), interactive category catalogue, product showcase, and shop contact integration.
- **Firebase Auth**: User signup, sign-in, and cross-device session synchronization.
- **Supabase Database**: Full PostgreSQL schema for categories, products, customer enquiries, orders, and payment ledgers.
- **Cloudinary Storage**: High-speed image hosting for product images and customer profile DP avatars.
- **Razorpay Payment Gateway**: Seamless online advance & balance payment checkout (`rzp_live_T547lttHOVL633`).
- **SaaS Admin Portal**: Master admin dashboard with passcode authentication, order status timeline updates, payment requests, and workshop cash transaction logging.
